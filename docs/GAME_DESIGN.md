# Game Design

## Core Vision
세계지도를 무대로 도시와 인재를 경영하고 외교와 전쟁을 통해 세계의 패권을 다투는 턴제 전략 게임.

## Core Loop
세계지도 → 도시 선택 → 명령 선택 → 지휘관 선택 → 내정/인사/군사/외교/계략 실행 → 출진/전투 → 월 종료 → AI 세력 행동 → 다음 달

## World
- 목표 거점 수: 100+
- 지역: 동아시아, 동남아시아, 남아시아, 중동, 유럽, 아프리카, 북미, 중남미, 오세아니아
- 연결: 육로 / 해로
- 거점 속성: 인구, 금, 식량, 농업, 상업, 치안, 방어, 병력, 훈련도, 사기

## Commander Stats
- 통솔
- 무력
- 지력
- 정치
- 매력
- 충성
- 야망
- 경험

## Commands
### 내정
개발 / 상업 / 치안 / 방어 / 식량 확보

### 인사
탐색 / 등용 / 포상 / 임명 / 이동

### 군사
징병 / 훈련 / 편성 / 이동 / 출진

### 외교
동맹 / 휴전 / 공동작전 / 지원 / 항복 권고

### 계략
정보 수집 / 이간 / 선동 / 매복 / 보급 방해

## Battle
전투 전용 타일 맵을 사용하며 지형, 병과, 지휘관, 사기, 보급, 계략이 전투 결과에 영향을 준다.

## UI Direction
- 모바일 가로 화면 우선
- 세계지도 확대/축소 및 드래그
- 선택 도시 정보 패널
- 큰 터치 영역
- 지도/도시/인물/전투 화면의 시각적 일관성
- 고급 2D 전략게임 분위기

## Copyright Direction
특정 상용 게임의 그래픽, 음악, 텍스트, 캐릭터 초상 등을 복제하지 않는다. 장르의 일반적인 전략 시스템을 참고하되 시각 자산과 구체적인 표현은 독자적으로 제작한다.
