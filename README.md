# Project-game

세계지도를 무대로 하는 턴제 전략 게임 프로젝트입니다.

## 목표
- 고전 역사 전략 게임의 깊이 있는 플레이 감각을 현대적으로 재해석
- 세계지도 100개 이상의 주요 거점
- 월 단위 턴제 전략
- 내정, 인사, 군사, 외교, 계략, 연구, 보급 시스템
- 지휘관 능력치, 충성도, 성장, 특기 시스템
- 육상/해상 이동 및 전술 전투
- 모바일 가로 화면에 최적화된 UI
- 독자적인 그래픽, 인물, 데이터 및 세계관 사용

## 개발 원칙
원작 게임의 이미지, 음악, 문구 등 저작권 보호 자산을 복제하지 않고 독자적인 게임으로 개발합니다.

## 개발 단계
### v0.1 Foundation
1. 세계지도 및 거점 데이터 구조
2. 세력/도시/지휘관 데이터 모델
3. 월 단위 턴 진행
4. 기본 내정 명령
5. 이동 및 도시 점령
6. 저장/불러오기 기반 구조

### 이후
- 인재 등용과 충성도
- 외교와 계략
- 병력/군량/보급
- 전술 전투
- 전략 AI
- 기술 연구 및 이벤트
- 그래픽/UI 고도화
- Android 빌드

## 플랫폼
초기 개발은 웹 기반 프로토타입으로 진행하며, 모바일 가로 화면을 기본 해상도로 설계합니다. 안정화 후 Android 패키징을 목표로 합니다.
